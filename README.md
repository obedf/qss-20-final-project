# Environmental Racism in the Data

**State- and County-Level Disparities in Environmental Burden**

Repo including all materials related to QSS 20 (Modern Statistical Computing) final project, by Obed Frimpong at Dartmouth College.

**Website:** [qss-20-website-obedf.vercel.app](https://qss-20-website-obedf.vercel.app/)

## About

This project examines environmental racism through quantitative analysis of state- and county-level disparities in environmental burden across the United States. It presents findings from QSS 20 (Modern Statistical Computing) through both a research paper and an interactive web visualization.

## Repository Structure

```
qss-20-final-project/
├── code/      # Jupyter notebooks for data processing and analysis
├── data/      # Raw and processed datasets
└── output/    # Generated figures and results
└── paper/     # Scientific writeup
```

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab

## Getting Started

### Clone the repo

```bash
git clone https://github.com/obedf/qss-20-final-project.git
cd qss-20-final-project
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the notebooks

```bash
jupyter notebook
```

Then open the notebooks in the `code/` directory and run them in order.
